# Безопасность интеграции Crush-PRO × МойСклад

- Проект **самостоятельный**. Не смешивать его заказы, товарные остатки, контрагентов или реквизиты с данными других проектов.
- В запросах на создание/предпросмотр заказов используется только зарегистрированная в МоемСкладе организация **Crush-PRO**, ID `62774749-69ef-11e7-7a34-5acf0009fff7`. Любой другой `organization_id` должен вызывать отказ.
- Ранее присланный в чат токен **отозвать**. Новый токен никогда не публиковать в переписке или исходных файлах.
- Токен хранить **только** в GitHub Actions Secret `MOYSKLAD_TOKEN`. По возможности предоставить отдельной учётной записи минимальные права.
- Репозиторий должен оставаться **Private**: запросы и результаты могут содержать коммерческие сведения.
- Пока Actions Variable `MOYSKLAD_WRITE_ENABLED` не равна `YES`, запись в МойСклад отключена.
- Для записи необходим сохранённый предпросмотр, совпадение контрольной суммы и отдельное явное `confirmed: true` после подтверждения пользователя.
- Не хранить в `requests/` и `results/` адреса покупателей, телефоны, банковские реквизиты, личные сведения, пароли или токены.
- В случае неопределённого результата POST искать документ по `externalCode` в МоемСкладе и **не повторять запись вслепую**.
- Включить двухфакторную защиту GitHub и ограничить права пользователей на Actions, Secrets и исходные файлы.
- Этот мост не выполняет оплат, отгрузок, приёмок, списаний или отправку в Telegram.
