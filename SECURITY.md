# Безопасность

- Ранее присланный в чат токен **отзвать**. Новый токен не публиковать и не присылать в чат.
- Токен хранится **только** в GitHub Actions Secret с названием `MOYSKLAD_TOKEN`.
- Выделить отдельного пользователя МоегоСклада с минимальными разрешениями на поиск товаров/контрагентов и создание заказов покупателей и поставщикам.
- Результаты заказов могут содержать коммерческие сведения и имена контрагентов: репозиторий должен оставаться приватным.
- Запись запрещена, пока Actions Variable `MOYSKLAD_WRITE_ENABLED` не установлена в `YES`.
- Даже при включённой записи необходим существующий предпросмотр, совпадающая контрольная сумма и явное `confirmed: true` **после подтверждения пользователем**.
- Не использовать `requests/` для телефона, адресов, платёжных данных и иных персональных данных.
- При неизвестном результате сетевого POST проверять реальный заказ в МоемСкладе по `externalCode`; не выполнять слепые повторы.
- Ограничить доступ сотрудников к репозиторию, действиям Actions и секретам; включить 2FA.
- Никаких оплат, отгрузок, приёмок и Telegram-отправок через этот мост.
