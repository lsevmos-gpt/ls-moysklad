# Безопасность интеграции Crush-PRO × МойСклад

**Актуально с 8 ноября 2026 года:** обработка перенесена с GitHub Actions на Cloudflare Worker `crush-pro-moysklad`. GitHub-репозиторий — только архив исходников и прошлых заявок. Никакие JSON-файлы из `requests/` больше не исполняются GitHub Actions.

## Рабочая система

- API МоегоСклада вызывается только из Cloudflare Worker, с токеном `MOYSKLAD_TOKEN` из секретов Worker.
- Защищённый интерфейс Worker использует секрет `BRIDGE_API_KEY`. Не публикуйте и не помещайте эти значения в исходники, переписку, коммиты, URL и логи.
- Отдельная база Cloudflare D1: `crush-pro-moysklad-db`. Содержит заявки, результаты, отметки исполнения и архив старой системы.
- Заявки и результаты из GitHub перенесены как архивные записи и не должны повторно исполняться. У каждой новой операции должен быть уникальный `request_id`.
- Для заказов закреплена только организация **Crush-PRO**, ID `62774749-69ef-11e7-7a34-5acf0009fff7`. Другие организации не допускаются.
- Создание заказа допускается только после сохранённого предпросмотра, совпадения согласованных полей и контрольной суммы, `confirmed=true` и явного подтверждения пользователя.
- Изменение существующих заказов требует собственных строгих проверок состояния, заказа, товарных позиций, суммы и подтверждения.
- Флаг `MOYSKLAD_WRITE_ENABLED` разрешает выполнение подтверждённых записей. Изменение флага **не является** согласием на какой-либо конкретный заказ.
- Не повторять POST/PUT автоматически при неопределённом результате. Перед новой попыткой проверять документ по `externalCode` или текущее состояние в МоемСкладе.
- Запрещено записывать персональные данные, ключи, банковские реквизиты и секреты в незашифрованные общедоступные журналы.
- Использовать минимально необходимые права, 2FA и регулярную ротацию токенов.

## GitHub — архив, не рабочее окружение

- **Сделайте репозиторий Private:** исторические запросы и результаты могут содержать коммерческие сведения. В момент миграции он был Public; сам перенос видимость репозитория не меняет.
- После подтверждения успешной работы Cloudflare удалите старый GitHub Actions Secret `MOYSKLAD_TOKEN`. Если токен ранее передавался открыто, отзовите его и выпустите новый для Cloudflare.
- Не добавляйте новые заявки в `requests/` ради выполнения. Этот механизм отключён.
- Исходники и история коммитов могут оставаться в GitHub как резервный архив, но для обработки складских операций GitHub больше не требуется.
